V12 收盤作業：基本面與題材標籤自動週期更新
================================================

目的
----
避免每天重複下載、解析並寫入約 2,000 檔完全相同的月營收與
官方產業題材標籤，同時保留每天正式雷達需要的即時題材熱度計算。

安裝後的「收盤作業」
--------------------
每天仍會執行：
1. 更新上市櫃普通股收盤資料與技術指標。
2. 更新到期的歷史訊號與實際進場績效。
3. 重新計算當日市場／產業／題材熱度。
4. 執行並儲存正式雷達。

基本面與官方題材標籤：
- 預設每 7 天更新一次。
- 7 天內再次執行收盤作業，只做輕量資料庫狀態檢查並自動略過。
- 若上市、上櫃其中一邊資料缺漏，或官方題材標籤尚未初始化，
  下一次收盤作業會忽略週期限制並自動修復。
- 不影響每天由行情計算的題材熱度。

安裝方式
--------
1. 解壓縮下載包。
2. 將下載包裡面的所有檔案與資料夾複製到 GitHub Desktop 使用的
   taiwan-stock-mcp 專案根目錄。
3. Windows 詢問時選擇「取代目的地中的檔案」。
4. 在 GitHub Desktop 填寫摘要：
   V12 weekly fundamental refresh
5. 按 Commit to main，再按 Push origin。
6. 等待 Render 顯示 Deploy live。

使用方式
--------
部署後仍然只要下：收盤作業

不需要指定日期、不需要另外下基本面更新，也不需要記得星期幾。

結果判讀
--------
未到更新時間時，fundamentalUpdate 會顯示：
- skipped: true
- intervalDays: 7
- reason: 距上次完整更新未滿7天
- nextDueAt: 下次可更新時間

到期更新時會顯示：
- skipped: false
- updated: 寫入基本面筆數
- autoThemeTags: 更新標籤筆數
- nextDueAt: 下一次更新時間

手動功能
--------
- get_v12_fundamental_refresh_status：只查看是否到期，不執行更新。
- refresh_v12_fundamentals：有特殊需要時立即強制更新。
- run_v11_daily_maintenance 的 force_fundamental_refresh=true：
  收盤作業中強制更新一次。

本更新沒有修改
------------
- 技術面計分
- 籌碼面計分
- 基本面計分公式
- 題材熱度計分公式
- 雷達買點、防守與停損規則
- 正式雷達每日執行與儲存規則
