V12 正式雷達：雙層進場劇本更新
================================

這次更新會讓每一檔正式雷達候選股固定附帶：

1. 激進低接點：價格區間、前段部位比例、承接條件
2. 確認買點：確認價、後段部位比例、不追價限制
3. 分批比例：激進低接與確認買進各占多少
4. 失敗條件：失效價格、收盤確認規則、處理動作與設定理由

安裝方式
--------

1. 解壓縮更新包。
2. 將更新包內下列檔案與資料夾複製到 GitHub Desktop 的
   taiwan-stock-mcp 專案根目錄，選擇「取代目的地中的檔案」：

   - server_v10_tools.py
   - v12_config.json
   - stock_db\v12.py
   - tests\test_v12_radar.py

3. 在 GitHub Desktop 確認出現 4 個變更檔案。
4. Summary 可填：Add V12 dual-entry playbook
5. 按 Commit to main，再按 Push origin。
6. 等 Render 顯示 Deploy live 後，下指令：V12正式雷達

判讀規則
--------

- 激進低接點是在結構支撐附近預設的小部位接法，不代表看到價位就一定買；
  還要看到低點不再下移、下影線或外盤回升至少一項承接訊號。
- 確認買點要求站回計算出的確認價，並維持在盤中均價之上。
- 若確認價已高於不追價線，雷達會直接標示不可追價，改等回測。
- 失敗條件預設採「收盤確認」；盤中短暫跌破只列警戒，不直接宣告收盤停損。
- 原有 idealEntry、maximumBuy、noChase、signalDefense、hardStop 欄位全部保留，
  不會破壞舊流程。
