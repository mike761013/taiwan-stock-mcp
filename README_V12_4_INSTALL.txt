台股雷達 V12.4 更新說明
========================

正式版本固定顯示：V12.4
不使用 V12.4.1、V12.4.2 等細分版本。

本次更新
--------
1. V12.4 正式評分升級為完整因子模型（內部模型修訂
   V12.4-COMPLETE-FACTORS-2），版本名稱仍固定顯示 V12.4：
   - 技術、法人／融資／外資／借券、TDCC 股權分散、內部人持股與設質。
   - 月營收、六種產業財報版型、現金流、ROE、資產負債與本益比／股價淨值比。
   - MOPS 重大訊息、增資稀釋、注意／處置證券與硬風險封鎖。
   - 美股／ADR／產業 ETF、匯率、美債殖利率、油價與台指期選擇權環境。
   - Fugle 五分鐘 K、VWAP、開盤區間回復與量能加速度。
   - 新聞情緒、分析師升降評文字、候選籃子集中度與 20 日相關性。
   - 交易所二位數產業代碼會先轉成正式產業名稱，再配對海外 ETF、BDRY
     與油價；TaiwanStockNews 依官方限制改為每檔每日一次單日請求。
2. 所有外部資料採缺值重加權，不把 API 缺資料誤算為 0 分；正式區仍要求
   資料完整度門檻。海外資料分成「本交易日已反映」與「次日盤前新增」，
   禁止使用尚未完成的同日美股資料。
3. 可執行績效改為 V12.4-NET-EXECUTION-1：
   - 只有日內最低價碰區間不再自動算整筆成交；須有承接代理訊號，純影線
     碰價預設只成交該段 50%。
   - 確認買點使用確認日收盤附近加 5 bps 滑價，不回填較早的盤中觸價。
   - 買進成本係數 1.000399、普通股賣出淨額係數 0.996601，退出另計 5 bps
     滑價；績效表保存成本模型、因子模型與成交模型修訂，互相隔離。
   - 績效摘要分開顯示「任一成交進場率」與「完整成交率」；新模型不混入舊版
     V12.4 樣本，必須重新累積實際可成交紀錄。
4. 保留既有五種策略與以下 V12.4 反轉續強功能。
5. reversal_continuation（反轉續強橋接）：
   - 捕捉 V 型反轉離開底部後的第一段健康整理。
   - MA60 改為階段判斷，不再要求完整 MA5>MA10>MA20>MA60 才能辨識。
   - 反轉背景成立時，五日漲幅上限動態放寬至 18%，但漲停與過度乖離仍禁止追價。
6. 黃金三角辨識：成立、形成中、近期形成與均線收斂。
7. nearMissObservations 不把差一項的股票直接消失，也不混入正式買進榜。
8. MCP 工具 explain_stock_v12(symbol) 逐項顯示單檔通過或淘汰原因。
9. 所有正式輸出的 version 與 accuracyEngine 統一為 V12.4。

安裝方式
--------
1. 關閉正在執行的 MCP Server。
2. 將更新包內 files_to_replace 的內容，依相同路徑覆蓋到專案根目錄。
3. 在專案根目錄執行：

   python scripts/verify_v12_4.py

4. 看到「V12.4 VERIFY PASSED」後，重新部署／啟動服務。
5. 呼叫 get_v12_radar_config，確認：

   version = V12.4
   accuracyEngine = V12.4
   strategies 包含 reversal_continuation
   factorModelRevision = V12.4-COMPLETE-FACTORS-2（出現在候選快照）

台表科 6278 防追價驗證
---------------------
- 2026-08-11：可由 reversal_continuation 辨識為反轉後第一段健康整理。
- 2026-08-26：漲停且距 MA20 約 18.9%，必須顯示 DO_NOT_CHASE（不追價）。

重要
----
黃金三角只提供結構加分，不會單獨產生買進訊號；仍須同時通過量能、位置、
均線支撐、收盤承接、官方事件風險與完整因子資料門檻。新聞情緒、夜盤或任何
單一外部因子都不能單獨產生正式買進訊號。
