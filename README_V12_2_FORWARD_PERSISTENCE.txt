V12.2 後勢持續性更新包
========================

目的
----
降低假突破、弱反彈、過熱追價與「只因收跌就被當成健康回檔」的誤判，
讓正式前十優先顯示較有機會延續上漲的訊號。

本版不會刪掉爆發股線索：
- 通過後勢持續性門檻：可進正式前十。
- 過熱、尚未確認或市場環境不利：保留在觀察名單。

主要修改
--------
1. 突破股要求更健康的收盤位置、MA20乖離及量能。
2. 收跌回檔必須同時量縮、低點未下移、收盤具承接、MA5/MA20未快速轉弱。
3. 新增 V12.2 後勢持續性資格，不合格者不進正式前十但仍保留觀察。
4. 使用同一份收盤資料計算全市場寬度與產業相對強弱，不增加報價API用量。
5. 弱勢市場中的普通突破訊號會降級，避免逆風追突破。
6. 新版績效學習只採用 V12.2 同版訊號，避免舊版績效污染新規則。
7. 保留四策略、200元主榜、高價強勢例外、雙買點、分批比例與收盤確認失敗條件。

安裝
----
1. 解壓縮本更新包。
2. 全選更新包內的檔案與資料夾。
3. 複製到 GitHub Desktop 使用的 taiwan-stock-mcp 專案根目錄。
4. Windows 詢問時選「取代目的地中的檔案」。
5. GitHub Desktop 的摘要填：Upgrade V12.2 forward persistence
6. 按 Commit to main，再按 Push origin。
7. 等 Render 顯示 Deploy live。

驗證
----
本機可雙擊 VERIFY_V12_2_FORWARD.bat。
部署後可執行：

validate_v12_release
limit_each=5
minimum_score=0

成功時 accuracyEngine 應顯示：V12.2_FORWARD_PERSISTENCE

重要說明
--------
測試通過代表程式規則與輸出語意正確，不代表保證上漲。
是否真的提高勝率，必須用 V12.2 新訊號累積至少 30 筆實際成交樣本後評估；
建議 50 筆以上再決定是否繼續調高或放寬門檻。
